# Introduction to ROS 2 Textbook

Welcome to the Physical AI & Humanoid Robotics textbook. This comprehensive resource is designed for advanced undergraduate and early graduate students in AI, robotics, computer science, and electrical engineering.

## About This Textbook

This textbook covers ROS 2 (Robot Operating System 2) concepts from fundamentals through advanced topics relevant to humanoid robotics. Each chapter includes:

- Clear learning objectives
- Theoretical foundations
- Hands-on labs with runnable code
- Exercises for practice
- References to authoritative sources

## Prerequisites

Before starting with this textbook, you should have:

- Basic Python programming knowledge
- Understanding of fundamental robotics concepts
- Familiarity with Linux command line

## Chapter Overview

1. **ROS 2 Fundamentals**: Core concepts including nodes, topics, services, and actions
2. **rclpy Python Agents**: Creating Python-based ROS 2 agents with parameters and lifecycle nodes
3. **Agent ↔ Controller Bridge**: Connecting high-level agents with low-level controllers
4. **URDF for Humanoids**: Robot description format for humanoid robots
5. **Testing & Deployment**: Best practices for testing and deploying ROS 2 systems

## Getting Started

To get the most out of this textbook, we recommend completing the chapters in order, as later concepts build on earlier ones. Each chapter includes hands-on labs that you should complete to reinforce your understanding.

## Technical Requirements

- Ubuntu 22.04 LTS or similar Linux distribution
- ROS 2 Humble Hawksbill
- Python 3.8 or higher
- Node.js 18+ for the textbook interface
