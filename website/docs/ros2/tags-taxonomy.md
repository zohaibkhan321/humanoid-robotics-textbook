# ROS 2 Tags Taxonomy

This document defines the standard tags used throughout the ROS 2 textbook to categorize content.

## Core Concepts
- `nodes` - Information about ROS 2 nodes
- `topics` - Topic-based communication
- `services` - Service-based communication
- `actions` - Action-based communication
- `qos` - Quality of Service policies
- `parameters` - Node parameter management
- `lifecycle` - Lifecycle nodes

## Communication & Architecture
- `pubsub` - Publisher/subscriber patterns
- `middleware` - DDS and middleware concepts
- `architecture` - System architecture patterns
- `design-patterns` - ROS 2 design patterns

## Python Development
- `rclpy` - Python client library
- `launch` - Launch files and system composition
- `cli` - Command line interface tools
- `testing` - Testing methodologies

## Control & Hardware
- `ros2-control` - ros2_control framework
- `controllers` - Controller interfaces
- `hardware` - Hardware interfaces
- `bridge` - Agent-controller bridge concepts

## Modeling & Simulation
- `urdf` - Unified Robot Description Format
- `xacro` - XML Macros for URDF
- `sensors` - Sensor integration
- `simulation` - Simulation environments

## Deployment & DevOps
- `docker` - Containerization
- `ci` - Continuous integration
- `deployment` - Deployment strategies
- `debugging` - Debugging tools and techniques

## Humanoid Robotics
- `humanoid` - Humanoid-specific concepts
- `kinematics` - Forward and inverse kinematics
- `gait` - Walking and movement patterns
- `balance` - Balance and stability
