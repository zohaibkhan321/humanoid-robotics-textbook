# Content Guidelines for ROS 2 Textbook

## Academic Rigor Standards

### Technical Accuracy
- All technical claims must be verifiable against official ROS 2 documentation or peer-reviewed sources
- Code examples must be tested and confirmed to work in the target environment
- Concepts should be explained with sufficient depth for advanced undergraduate/early graduate students
- Include mathematical formulations where appropriate for robotics algorithms

### Learning Objectives
- Each chapter must have 3-5 specific, measurable learning objectives
- Objectives should use action verbs (e.g., "implement", "analyze", "compare", "evaluate")
- Objectives must align with the chapter content and difficulty level

### Theoretical Content
- Provide sufficient theoretical background before practical examples
- Connect concepts to real-world robotics applications
- Include diagrams and visual aids where helpful
- Use consistent terminology throughout the textbook

## Readability Standards

### Text Complexity
- Maintain Flesch-Kincaid Grade Level between 12-14
- Use active voice wherever possible
- Limit sentence length to improve comprehension
- Define technical terms when first introduced

### Structure and Flow
- Organize content in logical progression from basic to advanced concepts
- Use consistent heading hierarchy (H1 for chapter, H2 for sections, H3 for subsections)
- Include transition sentences between sections
- End each section with a brief summary of key points

### Code Examples
- Include complete, runnable code examples with explanations
- Use meaningful variable and function names
- Add comments to explain complex logic
- Follow Python and ROS 2 best practices and style guides

## Exercise Standards

### Problem Design
- Include 3-5 exercises per chapter of varying difficulty
- Provide clear instructions and expected outcomes
- Include both conceptual and practical problems
- Offer hints or partial solutions where appropriate

### Assessment Criteria
- Exercises should reinforce key concepts from the chapter
- Include both analytical and implementation problems
- Provide clear grading rubrics for complex exercises

## Reference Standards

### APA Citations
- Follow strict APA format for all references
- Include at least 3 references per chapter from authoritative sources
- Prioritize peer-reviewed papers, official documentation, and textbooks
- Include URLs for online resources when available

### Source Attribution
- Attribute all diagrams, code snippets, and concepts to original sources
- Clearly distinguish between original content and adapted material
- Include license information when using third-party content

## Accessibility Standards

### Text Accessibility
- Use descriptive headings and subheadings
- Include alternative text for all diagrams and images
- Use sufficient color contrast for text
- Provide text alternatives for visual content

### Code Accessibility
- Include comments that explain code functionality
- Use descriptive variable and function names
- Provide alternative explanations for complex algorithms
